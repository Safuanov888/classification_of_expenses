# Приложение классификации трат

## Описание проекта
Этот сервис предназначен для автоматической классификации текстовых описаний личных расходов по категориям. Пользователь вводит текстовое описание траты, а ML-модель определяет категорию.

## Установка и запуск

### 1. Клонирование репозитория и настройка окружения
```bash
git clone https://github.com/Safuanov888/classification_of_expenses.git
cd classification_of_expenses
python -m venv venv
source venv/bin/activate
```

### 2. Установка зависимостей
Для работы приложения и запуска тестов установите зависимости:
```bash
pip install -r requirements_dev.txt
```

### 3. Запуск приложения
```bash
uvicorn app_final:app --host 127.0.0.1 --port 8000
```

После запуска интерактивная документация API доступна по адресу: **http://127.0.0.1:8000/docs**

## Переменные окружения
Создайте файл `.env` в корне проекта, как в примере env.example, или задайте переменные в системе.

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `APP_NAME` | `Приложение` | Название приложения |
| `APP_VERSION` | `1.0.0` | Текущая версия проекта |
| `LOG_LEVEL` | `INFO` | Уровень логирования |
| `CONFIDENCE_THRESHOLD` | `0.5` | Минимальный порог уверенности модели |
| `MAX_BATCH_SIZE` | `10` | Максимальное количество запросов в одном батче |

## Тестирование
Запуск автоматических тестов:
```bash
python -m pytest -v
```

## Диагностика и проверка работы
- **Проверка работоспособности:** `curl http://127.0.0.1:8000/health`.
- **Версия приложения:** `curl http://127.0.0.1:8000/version`.
- **Логи:** Основные события выводятся в стандартный поток вывода. Уровень детализации регулируется через переменную `LOG_LEVEL`.

## CI/CD
В проекте настроен GitHub Actions (`.github/workflows/ci.yml`). 
При каждом `push` и `pull_request` в ветку `main`:
1. Запускаются автоматические тесты.
2. Если тесты пройдены, собирается артефакт с файлами приложения.

## Проверка эндпоинтов через curl

Ниже приведены готовые команды для проверки всех маршрутов сервиса (при условии, что приложение запущено на `http://127.0.0.1:8000`). 

### Базовые проверки

**1) Корневой маршрут**
```bash
curl http://127.0.0.1:8000/
```

**2) Проверка работоспособности**
```bash
curl http://127.0.0.1:8000/health
```

**3) Версия приложения**
```bash
curl http://127.0.0.1:8000/version
```

**4) Список доступных категорий**
```bash
curl http://127.0.0.1:8000/categories
```

### Работа с ML-моделью

**5) Категоризация одной траты**
```bash
curl -X POST http://127.0.0.1:8000/categorize \
     -H "Content-Type: application/json" \
     -d '{"description": "такси до дома"}'
```

**6) Пакетная категоризация**
*(Лимит по умолчанию — 10 трат за один раз)*
```bash
curl -X POST http://127.0.0.1:8000/categorize/batch \
     -H "Content-Type: application/json" \
     -d '{"descriptions": ["оплата света", "билет в кино", "заказал пиццу"]}'
```
